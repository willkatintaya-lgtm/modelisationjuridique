# Boussole des amendements

Prototype d'interface : rédiger un amendement et le situer dans la discussion législative (texte examiné, concurrents, débat, navette, code).
Données réelles : article 4 du projet de loi logement en commission (groupes et personnes fictifs).

Ouvrir `index.html` dans un navigateur. Les données se régénèrent avec `python3 -I outils/construire_donnees.py`.
Les décisions de design et l'état du projet sont dans `CLAUDE.md`.
