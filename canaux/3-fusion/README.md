# Canal 3 — la fusion

Ce canal croise trois gisements et en tire un modèle d'interface sur papier :
- la maquette (`index.html`, `CLAUDE.md`, 497ce12) ;
- le canal 1 (`claude/canal-1-assemblee`, 7e48b00) ;
- le canal 2 (`claude/canal-2-corpus`, dd3116d ; le canal 2 travaille encore).

La session de refonte construit ce modèle dans le code.

## En dix lignes
1. **Le poids de la maquette vient du rangement, pas du contenu.** Quatre confusions l'alourdissent : les volets mêlent des lieux et un verbe (comparer) ; l'échelle mêle la granularité et la référence ; la feuille n'a pas de dos ; la scène est unique.
2. **Quatre allègements** précèdent tout ajout :
   - comparer devient un geste, et les volets passent de cinq à trois ;
   - « face à » devient une référence ;
   - chaque feuille a un verso (sa fiche) ;
   - on replie les identiques, les séries, les gages et les rédactionnels.
3. **Plusieurs interfaces dans un même espace** (charpente α, recommandée) : les mêmes feuilles, rangées autrement selon la question.
   - le plan : où ça se dispute ;
   - écrire : la maquette actuelle, allégée ;
   - le dérouleur : l'ordre d'appel, les sorts ;
   - l'histoire : les étapes et la navette ;
   - les thèmes.

   On change de rangement par la poignée basse, seul côté libre. Les feuilles voyagent d'un rangement à l'autre, et la feuille courante reste au centre.
4. **Convergence majeure** : les trois gisements demandent la même généralisation de la règle de comparaison, « une référence vierge, par défaut la commission ». Cela rouvre r.VIERGE ; c'est l'arbitrage n° 1.
5. **Le temps** n'a pas besoin d'un quatrième geste. Celui de l'objet est un changement de référence ; celui du processus est un ordre de parcours.
6. **Tout reste papier**, parce que la procédure l'est déjà : dérouleur, liste de vote, tableau comparatif, feuilleton.
7. **Treize directions** éliminables d'un geste (D1–D13), chacune avec le lieu où elle vit, ses données (★◐○), ses dépendances et son poids.
8. **Angles morts** :
   - le texte lisible n'est écrit nulle part (un alinéa réel est une instruction), d'où un cran « droit » ;
   - l'importance est concentrée, d'où un plan d'entrée ;
   - adopté ne veut pas dire « dans la loi » ;
   - personne ne disait comment on passe d'une interface à l'autre.
9. **Neuf arbitrages** pour l'utilisateur, avec une recommandation pour chacun. Le direct sur le dossier logement (séance du 16 au 20 nov.) demande une décision avant le 12 nov.
10. Pour la refonte : chaque direction derrière un interrupteur, pour que l'utilisateur élimine en regardant.
