# Arbitrage

Revue des 16 maquettes (zip « direction artistique » : `avant-<nom>.html`, `apres-<nom>.html`) par l'utilisateur, **module d'utilisation par module d'utilisation**, en vue d'une fusion.

- Un dossier par module : `NN-<module>/`.
  - `transcriptions.md` : les paroles de l'utilisateur, **verbatim**, horodatées, dans l'ordre, avec le contexte (maquette regardée, espace, geste). On ne corrige pas, on ne résume pas.
  - `enseignements.md` : ce que l'on en tire, **progressivement**. Chaque enseignement renvoie aux transcriptions qui le fondent (T1, T2…). Statuts : *entendu* (dit une fois), *confirmé* (redit ou validé), *arbitré* (décision de l'utilisateur), *ouvert* (question en suspens).
- `index.md` : les modules, leur état, les arbitrages déjà rendus.
- Sources des maquettes : voir `QUESTIONS-TECHNIQUES.md` à la racine.
